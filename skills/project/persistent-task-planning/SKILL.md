# Persistent Task Planning

## Workflow

Use only for genuinely multi-step or cross-session work. Create a plan with goal, scope, dependencies, acceptance checks, and status; keep findings and progress separate. Update notes after meaningful milestones and record decisions with rationale. On resumption, inspect repository state and verify completed steps rather than trusting stale notes. Keep files concise and avoid duplicating the entire conversation. Do not create planning-file overhead for simple tasks.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
