# Token Context Optimization

## Workflow

Load the smallest relevant skill, source range, and code area. Prefer targeted search and line-range retrieval over dumping whole repositories or documents. Summarize long sources with links, decisions, caveats, and unresolved questions. Remove repeated background while retaining constraints, acceptance criteria, tool results, and state. Never compress away safety boundaries or critical assumptions. At handoff, include a concise durable status note and authoritative file pointers.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
