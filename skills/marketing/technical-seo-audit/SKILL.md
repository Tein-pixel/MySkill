# Technical Seo Audit

## Workflow

Confirm domain ownership or authorization and search engine scope. Inspect robots directives, sitemap, canonical URLs, redirects, status codes, internal links, metadata, headings, structured data, mobile layout, page speed, and crawl anomalies. Use search console or crawl data only with authorized access. Prioritize by impact, affected URLs, and confidence. Do not promise rankings or use cloaking, doorway pages, hidden text, or link schemes. Separate technical fixes from content strategy.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
