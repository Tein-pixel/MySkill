# Ui Ux Design System

## Workflow

Inspect product, audience, platform conventions, existing components, and reference material. Define semantic color tokens, typography, spacing, radii, elevation, icon rules, motion, breakpoints, and component states. Choose patterns for product context rather than popularity. Build accessible components and document variants and constraints. Verify hierarchy, contrast, touch targets, keyboard behavior, text scaling, and responsive layouts. Use references for principles, not direct copying.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
