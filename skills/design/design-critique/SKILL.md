# Design Critique

## Workflow

Inspect the actual screen or prototype and identify target user and primary task. Evaluate information hierarchy, navigation, affordances, labels, consistency, feedback, error prevention, empty/loading states, accessibility, and responsive behavior. Tie each issue to user impact and a visible example. Separate blockers from visual polish and personal preference. Suggest specific corrections and a validation method. Do not equate aesthetic preference with evidence.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
