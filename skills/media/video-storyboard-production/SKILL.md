# Video Storyboard Production

## Workflow

Clarify purpose, platform, duration, audience, assets, limits, and rights. Create a concise narrative arc and script before shot planning. For each scene, specify subject, framing, action, audio, transition, and duration. Plan continuity, captions, safe framing, and licensed assets. Keep claims verifiable and disclose synthetic or sponsored elements where required. Review pacing and audio, then check aspect ratio, resolution, and file constraints.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
