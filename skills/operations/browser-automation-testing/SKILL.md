# Browser Automation Testing

## Workflow

Confirm target environment, permitted scope, test accounts, and allowed actions. Prefer stable selectors, accessible roles, and observable state over brittle coordinates or fixed sleeps. Cover success, validation, loading, empty, error, and navigation states. Capture console errors, network failures, screenshots, and steps. Do not bypass authentication, CAPTCHAs, access controls, rate limits, or anti-abuse systems. Never submit purchases, messages, public posts, or destructive forms without approval. Isolate test data.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
