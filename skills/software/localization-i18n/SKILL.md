# Localization I18n

## Workflow

Identify supported locales, fallback behavior, target markets, platform resource conventions, and translation ownership. Externalize user-facing strings and avoid concatenation that breaks grammar. Use locale-aware dates, numbers, currency, plural rules, sorting, and time zones. Design layouts for text expansion, RTL, mixed scripts, and accessibility. Preserve placeholders and translator context. Validate missing keys, malformed formatting, truncation, and language-specific flows. Do not use machine translation as final approval for legal, safety, or high-impact text.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve existing behavior and project conventions.
- Verify important changes with an observable check.
- Report evidence, caveats, and unverified areas separately.
