# Data Visualization

## Workflow

Clarify the question, audience, unit, time window, and decision. Inspect data provenance and quality before charting. Choose charts that fit the variable types and comparison task. Use honest axes, visible denominators, consistent units, accessible contrast, descriptive labels, and uncertainty where relevant. Avoid 3D distortion, misleading truncation, decorative noise, and overloaded dashboards. Separate descriptive, diagnostic, predictive, and causal claims. Include source and limitations so readers can interpret the visual accurately.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve existing behavior and project conventions.
- Verify important changes with an observable check.
- Report evidence, caveats, and unverified areas separately.
