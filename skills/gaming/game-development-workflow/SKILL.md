# Game Development Workflow

## Workflow

Clarify genre, player goal, platform, engine, input model, art scope, and constraints. Define the core loop and a small playable vertical slice before adding progression systems. Keep game state, simulation, rendering, and input responsibilities clear. Use deterministic tests for rules and save/load where possible. Profile actual frame-time and memory before optimizing. Playtest with explicit tasks and capture failure states.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
