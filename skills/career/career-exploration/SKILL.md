# Career Exploration

## Workflow

Start with interests, strengths, preferred activities, learning constraints, and career stage. Explain roles using current reliable job descriptions, not stereotypes or promises. Compare tasks, learning pathways, entry requirements, and transferable skills. Suggest low-risk exploration such as projects, classes, and informational interviews with trusted adults. Do not pressure the user into a path or guarantee salary, admission, or employment. Protect personal data when reviewing applications.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
