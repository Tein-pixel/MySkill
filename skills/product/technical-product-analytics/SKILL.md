# Technical Product Analytics

## Workflow

Start from product decisions and user outcomes, not the desire to track everything. Define event taxonomy, identity rules, properties, consent, retention, and data ownership. Avoid collecting sensitive fields unless explicitly necessary and approved. Validate event delivery, duplication, time zones, attribution, and bot/internal traffic. Define funnel and cohort calculations precisely. Distinguish correlation from causation and pair quantitative signals with user research. Document metric definitions and change history.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve existing behavior and project conventions.
- Verify important changes with an observable check.
- Report evidence, caveats, and unverified areas separately.
