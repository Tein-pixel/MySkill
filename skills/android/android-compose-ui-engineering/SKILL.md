# Android Compose Ui Engineering

Inspect current theme, navigation, tokens, and component patterns. Design loading, content, empty, error, offline, and permission states. Use reusable composables, stable state ownership, semantics, previews, insets, font scaling, RTL, contrast, and touch targets. Avoid fake controls and unnecessary recomposition.
