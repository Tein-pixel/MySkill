# Android Adaptive Ui

## Workflow

Measure available window size rather than branching only on device model. Define compact, medium, and expanded information architecture, including navigation bar versus rail, one-pane versus list-detail layouts, and content max widths. Preserve navigation, scroll, and playback state across resize, rotation, folding, and unfolding. Account for mouse, keyboard, touch targets, focus, and text input. Validate previews or screenshots across form factors and state continuity.

## Completion checks
- State what was inspected and what remains unknown.
- Keep the work within the user's scope and authorization.
- Preserve unrelated behavior and existing project conventions.
- Verify important changes with an appropriate observable check.
- Report evidence, caveats, and unverified areas separately.
