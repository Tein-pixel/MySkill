# Android Performance Investigation

Define reproducible scenario and baseline. Measure comparable builds/devices using Profiler, Macrobenchmark, Perfetto, or platform diagnostics. Separate app work from OS/radio/network effects. Optimize only the measured bottleneck and remeasure. Do not promise battery or thermal gains without evidence.
