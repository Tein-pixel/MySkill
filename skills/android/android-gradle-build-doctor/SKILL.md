# Android Gradle Build Doctor

Capture the exact failing task and log. Inspect wrapper, AGP, Kotlin, JDK, repositories, and version catalogs as one toolchain. Check official compatibility data before version changes. Reproduce narrowly, change one cause, rerun same task. Never randomly upgrade, suppress errors, or claim success without a successful task.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
