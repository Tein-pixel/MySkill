# Android Apk Release Validation

Confirm variant, application ID, version, SDK levels, signing expectations, and output. Keep secrets out of source. Build requested variant; inspect artifact existence, size, metadata, and signing state. Run tests and smoke checks where available. Distinguish build success from device/runtime validation.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
