# Android Code Review

Review against request first. Check nullability, parsing, coroutine cancellation, lifecycle leaks, state races, main-thread I/O, retries, permissions, API-level hazards, accessibility, secrets, and tests. Trace changed interfaces. Report actionable findings with severity, scenario, file, and remediation.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
