# Android Verification Gate

Compare diff with acceptance criteria and original feature inventory. Run focused tests, relevant suites, requested build variant, and artifact metadata checks. Inspect git status and secrets. Mark each criterion verified, partial, not run, or failed. Never turn intended work into claimed results.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
