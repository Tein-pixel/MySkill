# Android Feature Discovery

Translate request into outcomes, acceptance criteria, edge cases, and non-goals. Trace UI, state holder, domain, repository, data source, persistence, and tests. Search symbols and call sites. Identify contracts and compatibility constraints. Ask only when a product decision blocks progress. Do not edit before scope is clear.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
