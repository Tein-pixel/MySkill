# Android Engineering Workflow

Inspect project instructions, modules, Gradle wrapper, manifests, dependencies, architecture, tests, and CI. Define acceptance criteria and non-goals. Delegate to focused Android skills. Implement small vertical slices, run targeted tests, then broad checks. Preserve existing features. Report only commands and outcomes actually verified.

## Completion checks
- Confirm the task matches this skill's scope.
- Inspect relevant source, project, and user constraints.
- State assumptions and unknowns instead of inventing facts.
- Prefer small, reversible steps and preserve existing work.
- Verify with evidence appropriate to the task.
- Report what was verified, what was not run, and remaining risks.
